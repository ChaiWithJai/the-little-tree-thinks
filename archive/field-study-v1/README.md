# PrismML Bonsai field study archive

This folder preserves the first version of this repository. That work began as
a 48 hour developer ecosystem study and included the Nada Sadhana demo, local
model measurements, a setup guide, a field journal, and a PrismML DevRel pitch.

The material remains useful as historical evidence. It is not the current
Workbench setup or product contract.

## Contents

1. `docs/JOURNEY.md` contains the original field log.
2. `docs/CHRONICLE.md` contains the narrative version.
3. `docs/SETUP.md` contains the setup that was tested during the study.
4. `docs/SERVICE_BLUEPRINT.md` contains the Nada Sadhana service plan.
5. `docs/PRISMML_PITCH.md` and `docs/PRISMML_PITCH_5SLIDE.md` contain the
   original DevRel proposal.
6. `screenshots/` contains the retained demo evidence.
7. `scripts/serve.sh` contains the original llama.cpp model launcher.

Paths and runtime claims in this folder describe the reference machine at the
time of the study. Use the repository root README for current setup.
